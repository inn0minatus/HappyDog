This project is a web game prototype — a 2D browser runner (working title *Happy Dog Runner*): a branded, mobile-first promo game for a dog flea-and-tick tablet that ends in a "buy" CTA to tabletki.ua.

- Product brief / requirements: `docs/2d-browser-runner-bi-brief.md` (English translation of the client's cost-estimation brief — scope, features, deadline, and analytics events start_game / finish_game / click_buy).
- Authoritative build spec (from the brief + a design interview): `docs/2d-browser-runner-spec.md`. Locked decisions: finite ~60–90s level with Victory/Game-Over (not endless); auto-run + tap-jump only; 3 HP; ticks −HP, tablets +score/+HP; Armor power-up + sound in MVP; MVP ships ONE hero dog (5-breed select, duck/slide, combo deferred to phase 2); single promo-code CTA → tabletki.ua (with UTM params). Stack: Phaser 3 + TypeScript + Vite, static hosting, no backend; a `track(event, params)` adapter fans the 3 events to GA4 (gtag) + Meta Pixel (fbq). Client-dependent values (perf KPIs, timeline, promo code/URL, GA4+Pixel IDs, UI language, brand assets, env theme) are open in spec §11.
